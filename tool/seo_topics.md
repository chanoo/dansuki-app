## 대상과 원칙(바꾸지 말 것)
- 대상: 기본 어휘를 꾸준히 외워야 하는 중고등학생 · 예비 고1, 그리고 학부모. 상위권 · 시험 요령은 대상이 아님.
- 성적 향상 약속, 불안 조장(등급 컷 · D-day 압박), 가짜 희소성 금지. 시험일 중심 공부 계획 글 금지.
- '영어책'이라고 쓰지 않는다(이야기 · 작품 이름으로).
- 단숙이 기능은 사이트(docs/)에 이미 적힌 사실만.

- [ ] 영단어 객관식 문제, 공부가 될까 — 그럴듯한 오답 · 정답 확인의 역할(/method/ 출처 범위 안에서) [카테고리 memorize]

- [ ] 이전 범위 단어, 언제 다시 볼까 — 새 범위로 넘어간 뒤 누적 복습 하는 법(Nakata 외 2021, /spaced-review/와 겹치지 않게 종이 단어장 실천 위주) [카테고리 daily]
- [ ] 소리 나지 않는 글자 · 겹글자, 영단어 철자에서 짚을 자리 — know · listen · address 같은 예로 소리와 글자가 어긋나는 곳 모아 보기(규칙 과장 금지, /blog/how-to-memorize-english-spelling/와 겹치지 않게 단어 묶음 위주) [카테고리 basics]
- [ ] 영작할 때 떠오르지 않는 단어 — 뜻 → 영어 방향 연습을 문장 쓰기로 잇기(Webb 2009 범위 안에서) [카테고리 memorize]
- [ ] 영어 문장 속 주어 · 동사 찾기 — 긴 주어 뒤 동사가 어디서 시작하는지 짚는 연습(문법 용어 최소화, /blog/words-known-but-reading-hard/와 겹치지 않게 주어 · 동사 찾기만) [카테고리 basics]
- [ ] 쉬운 이야기로 영어 읽기 시작하기 — 아는 단어로 대부분 읽히는 글 고르기, 하루 한 문단(작품 이름으로, 과장 금지) [카테고리 basics]
- [ ] 밀린 영단어 복습 정리하는 법 — 며칠 쉬고 돌아왔을 때 새 단어를 멈추고 하루 양만큼 나눠 정리하기(자책 덜기, /blog/high-school-words-per-day/#backlog를 넘어 실제 정리 예시 위주) [카테고리 daily]
- [ ] 내 하루 공부량 재는 법 — 사흘 동안 떠올리기 방식으로 몇 개를 하는지 세어 보고 새 단어 수를 거꾸로 정하기(시간 · 개수 숫자 지어내지 않기) [카테고리 daily]
- [ ] 늦게 떠오르는 단어, 외운 걸까 — 맞혔지만 한참 걸린 단어를 어떻게 다룰지(Perfetti 2007 범위 안에서, /blog/forgot-english-words-next-day/와 겹치지 않게 속도 확인 연습 위주) [카테고리 memorize]
- [ ] 망각 곡선 숫자, 그대로 믿어도 될까 — 검색 상위 글에 흔한 '하루 뒤 67%' 같은 숫자를 단정하지 않고, 사람 · 내용마다 다르다는 점과 다시 보기의 의미(사이트 출처 범위 안에서, 새 숫자 만들지 않기) [카테고리 memorize]
- [ ] 품사가 바뀌면 뜻도 바뀌는 영단어 — book · face · point처럼 문장 속 자리로 뜻 고르기(문법 용어 최소화, /blog/memorize-multiple-meaning-words/와 겹치지 않게 자리 찾기 연습 위주) [카테고리 basics]
- [ ] 단어 시험 범위에 뜻이 여러 개일 때 — 학교 단어 시험 준비를 뜻마다 카드로 나눠 날을 두고 보기(시험일 압박 없이, 평소 공부 습관 위주) [카테고리 daily]
- [ ] 같은 동사로 시작하는 숙어 나눠 보기 — look for · look after처럼 헷갈리는 짝을 문장 장면으로 구분(뜻 나열 금지, /blog/how-to-memorize-english-idioms/와 겹치지 않게 짝 비교 위주) [카테고리 basics]
- [ ] 지문에서 막힌 문장으로 빈칸 카드 만들기 — 교과서 · 지문에서 고른 문장을 카드로 바꾸는 순서(단어 · 숙어 공통, 시험일 압박 없이) [카테고리 memorize]
- [ ] 기능어부터 다시 보기 — because · between · during처럼 문장마다 나오는 초등 기본 어휘를 문장 속에서 바로 떠올리는 연습(Perfetti 2007 범위 안에서, /blog/restart-english-basics/와 겹치지 않게 단어 묶음 · 예문 위주) [카테고리 basics]
- [ ] 혼자 단어장으로 난이도 맞추는 법 — 거의 다 맞히면 섞고 많이 틀리면 줄이기(Wilson 외 2019 범위 안에서, 85% 숫자를 과장하지 않기) [카테고리 memorize]
- [ ] 단어 카드 예문 고르는 법 — 교과서 · 지문에서 짧고 장면이 보이는 문장 고르기, 뜻이 드러나는 예문과 아닌 예문 비교(지어낸 효과 숫자 없이) [카테고리 memorize]
- [ ] 단어 공부, 하루 중 언제 할까 — 짧게 여러 번 나누기와 같은 시간 정하기(수면 · 시간대 효과 숫자 지어내지 않기, 사이트 출처 범위 안에서) [카테고리 daily]
- [ ] 외래어로 익숙한 영단어 다시 듣기 — 우리말 소리로 굳은 단어(초콜릿 · 바나나 등)를 영어 소리로 다시 익히기, 단어 묶음 위주(/blog/english-word-pronunciation/와 겹치지 않게 목록 · 연습 위주, 효과 숫자 지어내지 않기) [카테고리 basics]
- [ ] 소리만 듣고 뜻 떠올리기 연습 — 글자 없이 듣고 뜻을 말하는 혼자 · 둘이 하는 듣기 확인법(사이트 출처 범위 안에서) [카테고리 memorize]
